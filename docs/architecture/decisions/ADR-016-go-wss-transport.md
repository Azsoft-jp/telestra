# ADR-016 GoのWSS接続と受信ループ

Phase 01のローカル検証向けに採用する。ユーザーは2026年10月29日に公開資料の参照と依存物の取得を承認した。本番への接続、鍵の取得、課金資源の作成は承認範囲に含めない。

## 依存物と接続先

GoのWebSocket実装に`github.com/coder/websocket v1.8.15`を使用する。版とhashをgo.modとgo.sumへ固定する。[公式リリース](https://github.com/coder/websocket/releases/tag/v1.8.15)、[API仕様](https://pkg.go.dev/github.com/coder/websocket@v1.8.15)、取得したソースとISCライセンスを確認した。第三者コードは変更しない。

接続先は構成で指定した`wss://.../agent`だけとする。userinfo、query、fragment、別パスを拒否する。HTTPリダイレクトは同一ホストでも追わず、認証情報を転送しない。OSの証明書検証を使用し、専用CAを指定する場合も検証を維持する。環境変数のHTTP Proxyは使用しない。プロキシ経由の要件は別に検証する。

資格と一回限りの端末証明はヘッダーで送る。Origin、Cookie、Token付きURLは作らない。圧縮を無効にし、受信・送信ともテキスト16KiBまでとする。バイナリ、不正UTF-8、過大メッセージを拒否する。接続は10秒、書込は5秒、受信待ちは45秒までとする。

401/403と認証を拒否する切断では資格の失敗として停止する。形式違反、未信頼証明書、リダイレクトでも再試行しない。408/429/500/502/503/504と通信断は有限のRunnerへ返す。ライブラリの自由文、応答本文、接続先、資格をエラーへ転記しない。通信失敗時の即時Closeで解放エラーも検出した場合は、その失敗も返す。

## 接続と命令の順序

接続のたびに短命資格を検証し、新しい端末証明を署名する。署名済みsession.readyを検証し、保存済みより新しい接続世代だけを受け付ける。新世代を履歴へ保存してからhelloを送る。対応するcontrol.receiptを10秒以内に確認してから、Runnerへ接続成功を返す。

接続中は15秒ごとにHeartbeatを送る。受領待ちは最大8件で、送信イベントの期限までに対応する通知がなければ切断する。未知IDや重複した受領通知を拒否する。相手から通信が続いても、受領期限や資格期限を延長しない。資格の期限には接続を終了する。中断時は接続を閉じ、読取goroutineを回収する。

受信した命令は[ADR-015](ADR-015-go-wire-and-command-journal.md)の署名・契約・境界検証と永続履歴を通す。同じ命令ID・本文には保存済みの結果を返す。結果不明、内容の衝突、保存失敗、容量超過では停止する。未検証の命令を処理する経路は設けない。

このClientはdevelopment向けで、実行可能ジョブ数0、能力一覧は空とする。TunerNodeはsynthetic、Encoder役割はencoderと申告する。capture.start/cancelにはnot implementedを返し、媒体処理を行わない。Capture Permit内部の暗号検証と確定予約の実行は未実装である。

## 検証と残る問い

`NODE-01`のGo・Worker相互試験で、ローカルTLS、端末証明、能力登録、Heartbeat、未実装ACK、失効後の停止を確認した。`NODE-02`ではworkerdを停止・再起動し、Goのjitter付き再接続、接続世代の更新、予約intentと合成attemptの保持を確認した。TLS鍵・端末鍵・Tokenは試験中のメモリとIPCだけで扱い、証跡へ保存しない。

Goのrace付き単体試験では、再接続後の同一命令、永続履歴の再読込、偽署名、別家庭、旧世代、未知命令、バイナリ、過大入力、上限、受領待ちの期限、資格期限、中断を確認する。これらは実チューナー、録画成功、Linux実行、インターネット経路、本番Cloudflareを証明しない。

次に決める必要があるのは、Nodeへの初期設定と鍵の保管方法、Goからのjoin/rotate、資格更新の応答が失われた場合の復旧手順である。履歴の圧縮と結果不明の照合、プロキシ、時刻ずれ、実環境WSSも残る。ローカル試験の成功を、Phase 01全体や本番運用の完了とは扱わない。
